# Upstream code

- The inference integration adapts [VioAgnes/HulluEdit](https://github.com/VioAgnes/HulluEdit/tree/6bc38b2a89dcae5be5681b949bf2b1272ad291d4) by Yangguang Lin, Quan Fang, Yufei Li, Jiachen Sun, Junyu Gao, and Jitao Sang. The upstream README links to the MIT license. See [HulluEdit.txt](HulluEdit.txt).
- The LLaVA code follows [haotian-liu/LLaVA](https://github.com/haotian-liu/LLaVA). See [LLaVA.txt](LLaVA.txt).
- The Transformers compatibility files come from the HulluEdit distribution of [Hugging Face Transformers](https://github.com/huggingface/transformers/tree/v4.31.0). See [Transformers.txt](Transformers.txt).
- CHAIR scoring adapts [ZJUNLP/Nullu](https://github.com/ZJUNLP/Nullu) for COCO val2014. See [Nullu.txt](Nullu.txt).
- Caption singularization is extracted from [CLiPS Pattern](https://github.com/clips/pattern). See [Pattern.txt](Pattern.txt).
